# Game Screen Observer

An assistant skill designed to add conversation and context while someone plays a game. It uses individual screenshots to discuss visible events without taking control of the game.

The work focuses on the boundary between what an assistant can observe and what it can reasonably conclude. The instructions require checking that captures show the correct window, limit screenshots and retries, and explain missed or uncertain details. They also address spoilers, unrelated content on screen, and keeping commentary useful.

**What this demonstrates:** designing AI interactions around visual evidence, handling tool limitations, and balancing responsiveness with careful observation.

The folder contains an instruction-based skill that depends on compatible screenshot tools. It does not provide continuous video or game audio.
