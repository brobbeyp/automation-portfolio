# CookUnity Meal Planner

An AI-assisted meal-planning workflow built around a recurring problem: choosing meals that reflect personal tastes while keeping enough variety from week to week.

The skill defines how to inspect a changing menu, combine confirmed feedback with recent order history, and recommend meals within the user's quantity and price preferences. It also specifies how to reconcile existing cart items and check the final selection before handing control back for checkout.

**What this demonstrates:** designing personalized AI workflows, distinguishing direct feedback from assumptions, handling dynamic website content, and checking that an intended selection matches the actual cart.

The folder contains the assistant skill and reference guides for browser interaction, preference intake, and profile structure. It requires compatible browser tools and an authenticated account.
