# CookUnity preference intake

Ask only questions not already answered by a confirmed profile or the current request.

1. How many meals are needed?
2. Are there allergies or absolute exclusions?
3. Which proteins are preferred, and which foods should be limited?
4. Are fish and vegetarian meals acceptable?
5. Are breakfast, sides, snacks, drinks, bundles, or protein-only products eligible?
6. Is repetition acceptable? If so, how frequently?
7. How important is variety within the order and across weeks?
8. Are premium meals allowed? What is the maximum number or surcharge?
9. What familiar-versus-adventurous ratio is desired?
10. Are there nutrition targets or limits that should affect ranking?
11. Are there confirmed favorite or disliked meals?
12. May exact confirmed items be added to the cart after approval?
13. Will the user handle checkout, or do they want assistance through checkout?

Recent orders are inspected every run for context, so do not ask whether to inspect them unless access would exceed the user's requested account scope. Recommendations remain concise unless the user requests more detail.

Summarize answers as hard restrictions, preferences, cost controls, eligible categories, variety rules, authorization boundaries, and output preferences. Ask the user to correct or confirm the summary before saving it.
