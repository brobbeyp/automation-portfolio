# Authenticated Web Workflow

A reusable workflow design for AI assistants working on websites where a user is signed in. The goal is to make recurring tasks consistent: establish access, understand the request, inspect current information, prepare a proposal, and verify the result after approved actions.

The work defines how to separate personal preferences from website-specific instructions, handle login and missing access, and recover from uncertain actions without blindly repeating them. Supporting guides cover setup, preference profiles, and adapting the workflow to different sites.

**What this demonstrates:** translating a practical task into a reusable AI workflow, designing human approval points, and treating verification and privacy as part of the process.

This is an instruction-based skill for an assistant with compatible browser tools.
